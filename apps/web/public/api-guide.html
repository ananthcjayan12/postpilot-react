PostPilot external API

Use the deployed PostPilot origin as the base URL. In Settings → External API access, create a key and copy it once. Keep it on your app's server. Send Authorization: Bearer ppk_... for the routes below. Connect YouTube, Instagram, and Facebook in the studio Accounts page first.

Supported publishing

YouTube: videos and Shorts. Instagram: images, Reels, and 2–10 image carousels. Facebook Page: images and videos. Carousels target Instagram alone.

Upload flow

  1. POST /api/media/uploads with {"name":"clip.mp4","type":"video/mp4","size":12345678}. Save id, partSize, and parts.
  2. For each part, POST /api/media/uploads/{id}/parts with {"partNumber":1}. PUT exactly that part's bytes to the returned URL and record the ETag. For production R2 signed URLs, omit the bearer header on the PUT.
  3. POST /api/media/uploads/{id}/complete with {"parts":[{"partNumber":1,"etag":"..."}]}. Save the returned media id.

Each part is 8 MiB except the last. Upload sessions expire after 24 hours. Accepted MIME types: JPEG, PNG, WEBP, MP4, QuickTime, WEBM. Maximum 5 GiB per file. The localUrl in media responses is a studio preview URL.

Create and publish

POST /api/posts
{"title":"Launch day","caption":"Our new release","mediaId":"UUID","platforms":["instagram"],"action":"draft"}

POST /api/posts/{id}/publish
GET /api/posts/{id}

Draft first and retain the post ID before calling publish; this avoids creating duplicate posts if a create request times out. Publishing is asynchronous. Poll the post for status, targetStatuses, results, and lastError. Final statuses are published, partial, or failed. Use POST /api/posts/{id}/retry for failed targets. A target marked review requires checking the provider account before retrying.

For an Instagram carousel, use the first slide as mediaId, additional slides in carouselMediaIds in order, and platforms:["instagram"]. For a Short, use youtubeFormat:"short" and videoMetadata:{"width":1080,"height":1920,"duration":30}. To schedule, use action:"schedule" and a future UTC scheduledFor such as 2026-10-01T09:00:00Z.

Endpoint reference

MethodPathPurpose
GET/api/accountsConnected providers and readiness
GET/api/media, /api/media/{id}List or inspect assets
DELETE/api/media/{id}Delete asset and associated posts
GET/api/posts, /api/posts/{id}List or inspect posts
POST/api/postsCreate draft, schedule, or publish
PUT/api/posts/{id}Replace draft or scheduled post
POST/api/posts/{id}/publish, /retryPublish or retry failed targets
POST/api/posts/{id}/targets/{platform}/resolveResolve uncertain provider result
DELETE/api/posts/{id}/targets/{platform}Delete published provider item
GET/api/analytics, /api/settingsRead activity and preferences
PUT/api/settingsUpdate workspace settings
POST/api/ai/suggest, /hashtags, /thumbnail-copy, /thumbnailAI content services

JSON errors have error and sometimes validation details. Common status codes are 400, 401, 404, 409, 410, 413, and 503. API keys have full workspace access; revoke unused keys in Settings. Account OAuth and key management require a signed-in studio session.
